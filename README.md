# Farm

![How Farm works](public/farm-how-it-works.png)

Farm exists so trusted communities can amplify each other's public work on X without relying on noisy group chats and manual reminders.
Members join private Farms, share valid X post links, and Farm coordinates lightweight likes through official X APIs with minimal account access.
