# Farm

Status: Placeholder

## Purpose

Define Farm creation, joining, membership management, admin controls, and leaving a Farm.

## Scope

- Create a Farm.
- Generate and share a join link.
- Join a Farm through an invite link.
- View Farm members.
- Remove members as an admin.
- Delete a Farm as an admin.
- Leave a Farm as a member.

## Key Flows

- User creates a Farm and becomes admin.
- User joins a Farm from an invite link.
- Admin reviews and manages Farm members.
- Member leaves a Farm.
- Admin deletes a Farm.

## Open Questions

- Can a Farm have multiple admins?
- Should invite links expire or be revocable?
- What happens to historical engagement requests when a member leaves?
- What happens to historical engagement requests when a Farm is deleted?

## Acceptance Criteria

- A user can create a Farm.
- A Farm has at least one admin.
- Farm invite links allow authenticated users to join.
- Admins can remove members.
- Members can leave Farms.
- Admins can delete Farms.
